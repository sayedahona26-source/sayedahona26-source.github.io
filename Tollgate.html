FAQ

Good questions.

Does Tollgate train on my code?

No. Your code is never used to train models. Zero-retention mode deletes it as soon as the review is posted.

How is it different from a linter?

Linters check rules you wrote. Tollgate reads your repo in context and reasons about what the change actually does.

Which languages and platforms?

TypeScript, Python, Go, Java, Rust and more. GitHub today, with GitLab and Bitbucket next.

Can it block merges?

Yes. Make it a required check and choose which severities should block.

What does it cost?

Free for open source. Teams pay per active developer, and we only count people who open pull requests.
